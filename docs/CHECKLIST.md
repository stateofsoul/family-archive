# Ручная проверка

Используйте вымышленные данные. Эта таблица содержит ожидаемое поведение, а не отметки о пройденной проверке.

| № | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Открыть сайт в новом браузере | Пустой список, понятная кнопка создания |
| 2 | Создать заявку с заполненными обязательными полями | Переход к карточке, запись появляется в списке |
| 3 | Оставить имя пустым или ввести пробелы | Заявка не сохраняется |
| 4 | Ввести описание короче 20 символов | Сообщение о минимальной длине |
| 5 | Оставить период пустым | Заявка сохраняется, письмо просит уточнить период |
| 6 | Ввести 2000 символов в описание | Допустимо; более длинные данные сервер отклоняет |
| 7 | Отправить одну форму дважды | Создаётся одна запись |
| 8 | Изменить статус на «В работе» | Карточка, фильтр и счётчики обновляются |
| 9 | Скопировать письмо | Текст в буфере; при запрете доступа есть ручной вариант |
| 10 | Открыть чужую заявку в другом браузере | 404, сведения не показываются |
| 11 | Ввести HTML в имя | Он отображается как текст |
| 12 | Перезапустить сервер и открыть тот же браузер | Заявка сохранилась |
| 13 | Уменьшить окно до ширины 375 пикселей | Одна колонка, нет горизонтальной прокрутки |
| 14 | Пройти форму клавишей Tab | Все поля и кнопки доступны, фокус виден |
| 15 | Отключить JavaScript и отправить неверные данные | Сервер показывает ошибки, значения сохраняются |

## Как оформить найденную ошибку

Название: коротко указать действие и проблему.
Шаги: страница, введённые данные, нажатая кнопка.
Ожидание: что должно было произойти.
Факт: что произошло.
Среда: браузер и размер окна.
Приложение: скриншот или короткая запись.

Не называйте этот шаблон отчётом о найденном баге, пока не воспроизвели реальную ошибку.
