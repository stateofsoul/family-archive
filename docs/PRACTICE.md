# Небольшие задачи для доработки

## Работа с AI

Это примеры запросов для следующей итерации, а не журнал уже выполненных действий.

1. «Проверь функцию validate_request. Найди случаи, в которых пробелы или слишком длинный текст могут пройти проверку. Для каждого случая предложи входные данные и ожидаемый результат».
2. «Объясни, как добавить редактирование заявки в этот Flask-проект. Сначала предложи минимальный план. Учти серверную проверку, принадлежность заявки сессии и сохранение введённых значений при ошибке».
3. «Проверь CSS на ширине 375 пикселей. Предлагай изменения только для обнаруженных проблем и объясняй каждое».

После ответа модели сначала проверьте предложение, внесите небольшое изменение и запустите подходящий тест. Сохраняйте настоящие примеры ошибок и исправлений, чтобы объяснить свою работу.

## Figma

В этом проекте нет готового макета Figma. Для практики перенесите форму в два фрейма: 1440 и 375 пикселей. Добавьте подписи полей, состояния ошибки и фокуса. Сравните результат с работающей страницей. Это отдельное упражнение; не указывайте уверенное владение Figma только на основании наличия этого проекта.
