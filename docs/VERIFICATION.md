# Проверка проекта, 26 сентября 2026

## Что проверено

- Отправленный ZIP отдельно распакован: исходные 19 тестов прошли.
- Найдена ошибка при не-ASCII значении CSRF-токена. Раньше возникал TypeError, теперь сервер возвращает 400 с сообщением. Добавлены проверки кириллицы, emoji и пустого токена.
- После исправления: 22 проверки pytest прошли на Python 3.12 и Flask 3.1.2, Linux.
- Через настоящий локальный HTTP-сервер проверены главная, CSS, JavaScript, форма, создание заявки, черновик, изменение статуса, фильтры и повторный POST.
- В Node.js проверены счётчик, пробелы, корректный ввод, блокировка кнопки, возврат на страницу, фокус ошибки, копирование и запасной вариант при отказе буфера обмена. Это тесты логики с заглушками DOM, не браузерный прогон.
- База и локальный ключ не включены в ZIP.

## Что не подтверждено

- Ручной просмотр страниц в Chrome и Safari, мобильная вёрстка, управление клавишей Tab.
- Запуск START_WINDOWS.bat на настоящей Windows. Файл проверен по содержимому, но среда проверки работает на Linux.
- Установка на конкретном компьютере пользователя и поведение при занятом порте 5000.

## Ограничения первой версии

Черновик составляется по шаблону. Внешняя нейросеть и отправка писем не подключены. Логина нет: записи привязаны к cookie текущего браузера. Очистка cookie убирает доступ к старым заявкам; сам файл базы при этом остаётся. Для публичного сервиса нужна полноценная авторизация.

## Воспроизведение проверок

В папке проекта после установки зависимостей:

```text
python -m pytest -q
node tests/test_frontend.mjs
```

Вторая команда необязательна для запуска приложения и требует Node.js.
