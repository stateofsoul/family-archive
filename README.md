# Семейный архив

Небольшой учебный проект на Flask. В приложении можно сохранить известные сведения о человеке или семье, подготовить черновик обращения в архив и отметить статус заявки.

Данные хранятся локально в SQLite. Письма никуда не отправляются, сервис только собирает черновик из введённых данных.

## Что есть в проекте

- создание заявки;
- проверка обязательных полей;
- сохранение данных в SQLite;
- список заявок с фильтром по статусу;
- смена статуса заявки;
- подготовка черновика обращения;
- копирование текста письма;
- защита от повторного сохранения одной формы;
- тесты основных сценариев и ошибок ввода.

## Стек

Python, Flask, SQLite, Jinja, HTML, CSS, JavaScript и pytest.

## Запуск

Нужен Python 3.10 или новее. Откройте терминал в папке проекта, где находится `app.py`. При первой установке зависимостей нужен интернет.

На Windows:

```bash
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

На Linux или macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

После запуска откройте `http://127.0.0.1:5000` в браузере. Пока работаете с сайтом, оставьте терминал открытым. Чтобы остановить приложение, нажмите Ctrl+C.

## Как пользоваться

1. Нажмите «Создать заявку».
2. Укажите имя или фамилию, место поиска и известные сведения. Период можно не заполнять.
3. Сохраните заявку. Откроется её карточка с черновиком письма.
4. Скопируйте текст в почту, проверьте его и добавьте адресата и свои контакты. Отправка происходит вне приложения.
5. Когда начнёте поиск или получите результат, выберите нужный статус и нажмите «Обновить».

На главной странице можно посмотреть все заявки или выбрать конкретный статус. Статистика показывает общее количество заявок, независимо от выбранного фильтра.

## Как это работает

Браузер отправляет форму во Flask. Приложение проверяет поля и сохраняет запись в SQLite. Затем открывает карточку заявки, а Jinja подставляет данные в HTML. JavaScript отвечает за счётчик символов и копирование текста.

Черновик собирается по обычному текстовому шаблону. Нейросеть и внешние API не подключены, новые факты в текст не добавляются.

## Тесты

На Windows:

```bash
.venv\Scripts\python.exe -m pytest -q
```

На Linux или macOS:

```bash
.venv/bin/python -m pytest -q
```

Дополнительно можно проверить JavaScript, если установлен Node.js:

```bash
node tests/test_frontend.mjs
```

Эта проверка выполняется без браузера и проверяет логику обработчиков. Для запуска самого приложения Node.js не нужен.

## Файлы

- `app.py` содержит маршруты, работу с SQLite и сессией;
- `services.py` проверяет поля формы и собирает текст обращения;
- `templates` содержит HTML шаблоны;
- `static` содержит стили и JavaScript;
- `tests/test_app.py` содержит основные проверки;
- `requirements.txt` содержит зависимости проекта.

База создаётся автоматически в папке `instance`. Эта папка добавлена в `.gitignore`.

## Ограничения

Это локальный учебный проект без регистрации пользователей и отправки писем. Заявки привязаны к сессии браузера. Если удалить cookie, открыть другой браузер или закончить сеанс в режиме инкогнито, старые записи останутся в базе, но новая сессия их не увидит.

Редактирования и удаления заявок в этой версии нет. Проект предназначен для запуска на своём компьютере, а не для публикации в интернете. GitHub хранит код, но не запускает Flask через GitHub Pages.

Для демонстрации используйте вымышленные данные.
